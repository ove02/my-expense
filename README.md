# My Expense - GitHub Pages edition

A standalone, offline-first expense tracker for iPhone and other devices. Black/neon-green icon and a 1.5-second animated opening credit: Developed By Ove.

## Publish from a brand-new repository
1. Create a **public** GitHub repository (example: `my-expense`).
2. Click **uploading an existing file** (or Add file > Upload files).
3. **Open this extracted folder, select ALL files inside it, and upload them**. Do not upload the enclosing folder or ZIP. The file `index.html` must appear directly at the repository root.
4. Commit changes.
5. In Settings > Pages, choose **Deploy from a branch**, `main`, `/(root)`, and Save. Leave **Custom domain empty**.
6. Check Actions for deployment status and visit `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`. Allow several minutes.
7. On iPhone, open the URL in Safari, Share > Add to Home Screen > Add.

## Features
Manual and natural-language expense entry, date-grouped history and totals, budgets, savings goals, reports, recurring templates, search/edit/delete, dark mode, and CSV/JSON backup tools. Check the More tab for the available tools. Some features like AI receipt photo scanning, cloud sync, and notifications require additional services and are **not** active.

## Privacy and backups
Data is saved in this browser/device's local storage, not synced from the prior Expo app, prior PWA, or Google Sheets. Keep backups. Do not clear browser storage without exporting your data. A fresh repository name creates a distinct web origin/path and does not automatically migrate your previous records.

This is a static web app. No Node.js, Expo, Apple Developer membership, or API key is needed. Never upload private API keys to GitHub.
